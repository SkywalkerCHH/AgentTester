# AgentTester
An LLM-based Tool for Unit Test Generation with Automatically Generated Prompts

## Dataset
We utilize the following three representative Java projects sourced from GitHub as benchmark projects.

1.jInstagram. 2015. (2015). https://github.com/sachin-handiekar/jInstagram

2.tabula java. 2017. (2017). https://github.com/tabulapdf/tabula-java

3.zappos json. 2016. (2016). https://github.com/Zappos/zappos-json
